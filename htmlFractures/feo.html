Flood Test 63

Original Game Link: [LEGACY] Flood Escape Operation

FEO:R Game Link: FEO:R / Cancelled Build

Flood Test 63 (previously known as Flood Escape Operation) was a Flood Escape fangame on Roblox made by me and moakdoge. Started on October 9th, 2020, FT63 would end up going from a hub of random stolen maps to (eventually) a hub of original maps. (Both versions are playable in the original game link!)
It was built upon ForbiddenJ's Open Flood Test engine, although during 2024, there were plans to swap engines to a custom one instead.

Flood Test 63 as a game was cancelled on August 10th, 2024, and since then the only things to come out of it were unused OSTs and track remakes. Don't expect Flood Test 63 to be playable anytime soon.

Versions

Flood Escape Operation

Original Version: 2020 - 2021

This was the version with stolen maps. It had some original maps sprinkled in (i.e. Snow Sad Day, Old FEO Facility), but most were random FE2 maps left in the toolbox. The last update of the original versions was in 2021, as I had temporarily quit Roblox on January 17th, marking an end for that era.

Scrapped Full Release: 2022

Shortly after FEO:D seized development, Roblox committed the BOMBSHELL that was the Audio Privacy update. Now, no longer being able to just grab any audio I wanted from the toolbox was sad, but this update also made uploading audio files FREE! Albeit at a rate limit of days. So, I began work on a new version of FEO, one with custom music and fully original maps (again)! This version's the whole reason I even make music to this day! It got cancelled sometime after, but I don't remember the reason.

Flood Escape Operation: Deluxe / FEO:D (2021 - 2022?)

A planned "sequel" to the original Flood Escape Operation! It's also the first to only consist of original maps! What a wonder! ...Unfortunately, because of Roblox changes, the game itself is unplayable.

Technically, this was the first era to consider a custom engine instead of Open Flood Test, but the engine was so bad that it wasn't considered. This is also where some FEO:R maps were originally concepted! Take Broken Premises, for instance! It was a remake of Sinking Facility from THIS game! :D

Flood Escape Operation: Retake (2022 - 2024)

Alternative Names: Flood Escape Operation: Overhaul

FEO:R was the final version of FT63 (the game). It would follow along with what the Scrapped Full Release had to offer, along with bringing some newer things to the table, like overhauled UI, elements from Flood Escape 2's agility update not included in Open Flood Test, some engine refactoring, etc. Here's a list of everything FEO:R introduced into the engine.

  • Sliding
  • Air Diving
  • Death Messages
  • Dynamic Time Limit
  • The Custom Walljump / Water Properties from Flood Escape 2 that existed back then
  • Map Events (disabled by default on the cancelled build iirc)
  • Instance Values replaced by Attributes
  • Custom UI in Maps (barely)
  • Settings Menu
    • Map SFX
    • UI SFX
    • Volume Sliders
    • Keybinds
